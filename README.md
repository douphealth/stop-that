# STOP THAT! — Make the noise stop

A fast, interactive guide with **78 source-backed fixes** for unwanted notifications, pop-ups, autoplay, privacy prompts and AI features across **17 apps** (iPhone, Android, Windows, Chrome, YouTube, WhatsApp, Slack, Discord and more).

## Features
- Instant search that ranks results by app, title and keywords (no AI guessing)
- Filters by type, device and app, plus starred fixes saved in your browser
- Step-by-step checklist with a progress bar on every fix
- Honest labels: **Can disable**, **Can reduce**, **No confirmed switch**
- Every fix links to official vendor documentation, with its review date

## Edit the content
All fixes live in `src/data/fixes.json`. Add an entry with the same fields and it shows up everywhere.

## Run locally
```bash
bun install
bun run dev
bunx vitest run
```

Built with TanStack Start, React 19 and Tailwind CSS v4.
